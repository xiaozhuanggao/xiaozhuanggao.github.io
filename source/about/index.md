# 高晓庄

**工程师 / 架构师 / 偶尔读点哲学和经济学**

## 这里写什么

这是一个**不严肃的个人札记**，主要分两类内容：

- **技术向**：Java / Go / Python 后端架构、AI 工程化、云原生踩坑
- **非技术向**：读了点哲学和经济学之后的零散感想，儒家、道家、社会经济学都有

写下来不是为了"输出倒逼输入"那一套高大上的理由——纯粹是因为**不写下来，过几天就忘了自己当时想了什么**。如果你刚好也对这些话题感兴趣，欢迎翻翻。

## 工作身份

本职是软件工程师 / 架构师，做过企业级微服务、.NET 到 Java 的迁移、云平台虚拟化，最近一两年在折腾 AI 应用工程化。具体可以看[项目作品集](/projects/)和[简历](/resume/)。

但这只是一个职业身份。**技术做久了会发现，很多问题不是技术问题——是关于"为什么做"、"做给谁"、"值不值得做"的问题**。这些问题技术书里答不上来，所以会去翻哲学和经济学。
